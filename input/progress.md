## 当前边界与未决事项

- 取消依赖底层响应 signal；不能终止任意 Promise 或同步阻塞，也不保证服务端停止计费。
- readFile 期间取消已有真实文件测试；readdir 与路径解析只能在等待前后检查，无法保证到期立即退出；独立单工具超时预算尚未实现。
- 忽略 signal 后迟到返回的操作已有模拟测试，不支持强制中断；真实 HTTP 慢响应体未验收，res.text 非超时传输错误尚未细分。
- 当前 Loop 使用非流式 callLLM；流式路径未接入这套取消和错误分类。
- typeof 校验仅按当前工具类型验证，不等同完整 JSON Schema；路径 guard 不等同完整沙箱。
- stopDetail 保存异常结束兜底的原始值；errorDetail 只表示终止性的请求错误。
- rounds 只统计 callLLM 成功返回；重试总数不因某一轮成功而重置。
- reasoning_content 去除仅有历史简单任务证据，不能据此断言质量无退化。
- clear_thinking、usage 与资源包扣减关系仍未查清，涉及相关实验时再核对。
